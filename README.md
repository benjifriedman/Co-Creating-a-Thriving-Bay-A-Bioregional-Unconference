# Bay Delta Bioregional Unconference Website

A simple, responsive single-page website for the Bay Delta Bioregional Unconference event. This site provides information about an unconference focused on bioregional collaboration and ecological community building in the Bay Delta region.

Live page: [https://benjifriedman.github.io/Co-Creating-a-Thriving-Bay-A-Bioregional-Unconference/](https://benjifriedman.github.io/Co-Creating-a-Thriving-Bay-A-Bioregional-Unconference/)

## Overview

This is a static HTML/CSS website designed to:
- Announce and provide details for the Bioregional Unconference event
- Share information about the Bay Delta bioregion
- Display schedule and registration information
- List potential discussion topics
- Showcase supporting organizations

## Technical Details

The website is built using:
- HTML5
- CSS3 (with responsive design)
- Pure vanilla JavaScript-free implementation
- Mobile-first approach with media queries

### Features

- Responsive design that works across all device sizes
- Hero section with background image
- Clean, modern styling with a nature-inspired color palette
- CSS Grid implementation for topic listings
- Semantic HTML structure
- Optimized for accessibility

### Color Scheme

- Background: `#f4fbe4`
- Header/Footer: `#a3c9a8`
- Accent: `#5b865c`
- Text: `#2e2e2e`
- Links: `#2c703d`

## Local Development

To run this website locally:

1. Clone the repository
2. Open `index.html` in your web browser
3. No build process or dependencies required
